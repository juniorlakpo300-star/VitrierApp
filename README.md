# VitrierApp

Application web mobile-first pour un vitrier professionnel (vitres, fenêtres, balcons, garde-corps).

## Lancer localement

```bash
python3 -m http.server 4173
```

Puis ouvrir [http://localhost:4173](http://localhost:4173).

## Fonctionnalités

- Accueil avec présentation et slogan
- Galerie responsive de designs
- Catalogue produits vitrerie avec recherche + filtres (prix en FCFA)
- Détail produit avec CTA (devis / panier)
- Assistant IA interactif avec formulaire + analyse basique d'image
- Demande de devis
- Contact rapide (WhatsApp, téléphone, localisation)
- Avis clients et section À propos
